# Glossary

**Architecture feature space**
The multidimensional space formed by the validated BacSelect structural genome
features after their defined transformation.

**Assembly accession**
Identifier assigned to a genome assembly. BacSelect uses the GenBank `GCA_`
assembly accession as its canonical assembly identifier.

**Complete genome**
An assembly category used by the public archive. BacSelect applies additional
eligibility rules beyond this label.

**Diversity ladder**
The deterministic ordered list from which BacSelect panels are taken.

**Genome architecture**
Structural properties of a genome, including genome size, replicon structure
and repeat organisation.

**N**
The number of genomes requested in a BacSelect panel.

**Nested panel**
A panel design in which a smaller panel is a prefix of every larger supported
panel from the same release.

**Percentile coordinate**
A feature value transformed to its position within a defined empirical
distribution.

**Replicon**
A chromosome, plasmid or other independently represented DNA molecule in an
assembly.

**Selector**
The deterministic algorithm used to order candidate genomes into the diversity
ladder.

**Source universe**
The frozen set of genome assemblies eligible for a particular BacSelect
release.

**Structural distance**
Distance between genomes in the validated BacSelect architecture feature space.
