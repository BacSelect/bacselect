# Core concepts

BacSelect is built around a few distinct ideas.

- [Source universe](source-universe.md): which genomes are eligible.
- [Genome architecture](genome-architecture.md): which structural properties are measured.
- [Species balancing](species-balancing.md): how heavily sampled species are prevented from dominating feature scaling.
- [Structural distance](distance-and-coverage.md): how BacSelect measures representation in architecture space.
- [Nested panels](nested-panels.md): how supported panel sizes relate within a release.
