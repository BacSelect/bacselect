# Source universe

BacSelect does not begin with "all bacteria".

It begins with a reproducibly defined set of eligible public complete bacterial
genome assemblies.

For BacSelect v1, the proposed source universe uses the INSDC/GenBank assembly
archive, retrieved through NCBI Datasets. The canonical assembly identifier is
the GenBank assembly accession beginning `GCA_`.

## Why define the universe first?

A panel can only be interpreted relative to the genomes from which it was
selected.

The source universe must therefore be frozen and recorded before selection.

## What this does not solve

Public archives reflect what has been sampled, sequenced, assembled, deposited
and classified.

BacSelect can control how genomes are selected within its defined universe. It
cannot remove biases already present in the archive.

For the exact eligibility rules, see the
[scientific specification](../scientific-specification.md).
