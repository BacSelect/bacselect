# BacSelect documentation

**Bacterial genome diversity, at the scale you need.**

BacSelect addresses a practical question:

> We need a manageable set of bacterial genomes. Which ones?

The intended workflow is simple: choose a panel size, **N**, and obtain a
deterministic, versioned set of complete bacterial genomes selected to span
genome architecture within a defined public source universe.
