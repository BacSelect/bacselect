# Releases

BacSelect is designed for immutable monthly scientific releases.

No scientific BacSelect release has yet been published.

## Release identity

A released result will be identified by at least:

- BacSelect release, such as `2027.04`;
- selector version;
- architecture-schema version;
- panel size N.

Together, these identify the exact scientific result used in an analysis.

## What happens on the first of the month?

The first day of the month is intended to start a new source snapshot.

It is not a publication deadline.

The new release is published only after the full workflow passes its required
validation and provenance checks.

If it fails, the previous validated release remains current.

## Why immutable releases?

Public genome archives change over time.

Assemblies can be added, updated, suppressed or reclassified. A BacSelect panel
must therefore be tied to a frozen source universe rather than silently changing
under the same release name.

Published historical releases will not be rewritten.
